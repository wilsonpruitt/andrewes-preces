# Andrewes Preces Privatae — trilingual edition (Greek · Latin · English)

Wroot Press edition of the 1853 Parker printing (1675 Sheldonian text). This repo holds transcription, translation, and print prototypes. **Print layout is DECIDED (revised 2026-08-05): originals verso, English recto** — prototype C, the "Loeb" (Part I's Greek and Latin side by side in two columns on one leaf, Parts II–III at full measure, the English always on the facing page). It replaced the 1675 mirror on measurement — 0 units too tall against the mirror's 130, and one structure for all three parts instead of two; the trade is at `EDITION-SHAPE.md` §6b. ⚠ **The page-faithfulness rule is unchanged and non-negotiable**: transcription stays strictly page-faithful, never merging or re-splitting printed pages. Every layout is built from page-keyed fragments, so a merged page is unrecoverable in all of them.

## Session protocol

1. **The current front is the NOTES PASS. Read [`BRIEF-notes-pass.md`](BRIEF-notes-pass.md) FIRST** — it is written to be picked up cold and carries the state, the working loop, the rules, the per-page hazard lists and the patterns to watch. Then `NOTES-CONVENTIONS.md`, which governs every note. `next-session-resume.md` is the **history** behind both — consult it when the brief points there, don't read it front to back.
2. Then `M3-HANDOFF.md` (the volume-run recipe) and `CONVENTIONS.md` (transcription + translation rules). Follow them exactly; do not re-derive or drift. `STRUCTURE.md` has the volume map and page-offset anchors.
3. Day 1 files (`part1/day1-transcript.md`, `part1/day1-english.md`) are the format reference — match them precisely.

## Hard rules

- **Vision transcription only.** The PDF has no usable text layer; all OCR of the Greek is garbage. Read the 200-dpi images (`pdftoppm -jpeg -r 200`), one spread (2 leaves) per pass, verbatim; `[?]` for unreadable; never infer Greek from context.
- **Verify printed page numbers by eye** at the start/end of every extraction batch — the Google scan has duplicate leaves (42/43 scanned twice; offset is +18 before printed 44, +20 after). Record new anomalies in STRUCTURE.md's anchor table.
- **Translate the Greek** (Part I); Latin is the construal witness; English line-keyed, thou-form AV/BCP register per CONVENTIONS §8–10.
- **Brightman 1903 / Newman / Neale are cribs only** — consult after drafting, never copy, never import Brightman's ordering.
- **No git push, no deploy** — protected actions, per-action OK from Wilson. ⚠ **The repo HAS a remote** (`origin` → github.com/wilsonpruitt/andrewes-preces); older notes said it never had one and were wrong. Verify with `git remote -v`, never from prose. Commit locally: content commit + (if needed) notes commit, then update `next-session-resume.md` as the last commit of the session.
- Translation prose sessions run on **Opus** (Wilson's opus-for-authored-prose rule). If this session's task is a volume day and the model isn't Opus: ⚠️ Wilson — check your model. (Say it once, then proceed as he decides.)

## Build (prototypes / future edition)

`python3.11 tools/proof2tex.py` builds the **whole-volume proofing copy** (`prototypes/volume-proof.tex`; `--part 1|2|3` for one part) — continuous flow, both layers, not the mirror. `python3.11 tools/transcript2tex.py` builds the **whole-volume edition layout** (`prototypes/volume-loeb.tex`, 613 leaves; ⚠ **run xelatex TWICE** — the contents page needs two passes; `--part N` likewise; `--layout mirror` still builds prototype B for comparison) and regenerates `prototypes/fragments/`, which the three M2 prototypes still `\input`. Both builders import their parser and renderer from `proof2tex.py` — **fix a parsing bug once, there**. The edition carries **its own continuous folios** with the 1853 page as a shoulder-note in the inner head (§6a — layout-agnostic, it survived the change of layout).

⚠ After building, run `python3.11 tools/transcript2tex.py --fit`. **It reports measured BOX HEIGHTS, not page marks, and that is deliberate: a minipage overruns in silence instead of breaking, so page marks would report no overflow however bad it got.** Currently 0 of 596 units are too tall. ⚠ Before changing any column width, run `python3.11 tools/measure_lines.py` — 839 of Part I's 6,759 sense-lines already turn in the two columns, and the **Latin** column turns more than the Greek, so widening the Greek makes the total worse. TeX packages paracol/bidi/zref/auxhook are user-installed from the frozen TL2025 repo (system tlmgr can't cross-install from 2026 CTAN). Cardo covers polytonic Greek + Hebrew; Hebrew needs `\RL{}` (bidi). ⚠ The preamble sets `\raggedbottom`, so **`\vfil` will not centre anything vertically** — its glue competes with raggedbottom's and lands the block a third of the way down. Display leaves use `\dropto{}` (a fixed drop) or `\fullleaf{}` (a box of exactly `\textheight`, inside which `\vfill` behaves). ⚠ The editor's preface is `prototypes/front/preface.tex` — **a DRAFT for Wilson's voice**; its claims are grounded in CONVENTIONS/EDITION-SHAPE/`apparatus/`, so changing one there means changing it here.
